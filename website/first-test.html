Two ways onto a board.

Flash a release if you just want it running, or build from source for full control.

Flash a release — esptool only.

Grab the matching pair from Releases for your target — esp32, esp32c3, or esp32s3.

# Wipes the board and installs everything: bootloader, partitions, app
python -m esptool --chip esp32 write_flash 0x0 esp32.firmware.factory.bin

# Or, over the device's own OTA page once it's already running:
# open http://<device-ip>/#/ota and upload esp32.firmware.bin

Build from source — full control.

Install ESP-IDF 5.2–6.0 and make sure idf.py and openssl are on your PATH.

idf.py set-target esp32
idf.py -D SDKCONFIG_DEFAULTS="sdkconfig.defaults;boards/sdkconfig.defaults.esp32" build
idf.py -p /dev/ttyUSB0 flash monitor

The first build generates a development reader identity under main/certs/. It’s gitignored and for development only — read main/certs/README.md before using it for anything else.

What each line actually proves.

I aliro/app     : Aliro HomeKey starting
I aliro/access  : credential 'dev-credential' registered
I aliro/access  : lock output on GPIO 2 (active high), unlock 3000 ms
I nfc/pn532     : PN532 found, firmware 1.6
I aliro/reader  : reader ready, waiting for a device
I aliro/net     : joined 'YourNetwork' -- configuration UI at http://192.168.x.x/
LineWhat it actually proves
credential registeredThe Aliro SDK initialized and a credential’s key slot was derived — not that a phone can use it yet.
PN532 found, firmware X.YThe chip answered on the configured SPI/I²C pins. Wiring and bus selection agree with the physical switch.
reader ready, waiting for a deviceThe poll loop is running. It does not yet mean a tap will be recognized — that needs an enrolled credential.
joined ‘…’ — configuration UI at …Wi-Fi connected and the web server is listening. Open that address to configure hardware, network, and lock settings.
If you see no PN532 answered on the configured SPI/I²C pins instead — almost always the module is on 5V instead of 3.3V, or its mode switch is still on I²C/HSU while the config says SPI. See Hardware for the wiring table.
