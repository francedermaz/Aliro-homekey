Five betas, one working reader.

Every release is on GitHub with full notes and firmware for esp32, esp32c3, and esp32s3. This page is the short version.

2026-08-20 · latest

v0.5 [beta]

Google Home / SmartThings now show real lock activity history instead of unattributed state changes — unlock/lock operations report the correct Matter operation source (Aliro tap, auto relock, or remote command). Also the release that fixed a two-day CI breakage: the build container had floated onto IDF 6, which dropped a component this firmware needs.

2026-08-16

v0.4 [beta]

The first build that reads a phone. An iPhone carrying an Aliro credential provisioned by Apple Home opened the lock over NFC — a fast transaction in 569 ms against a stored key, and a standard one running the full handshake. The PN532 driver was rewritten where it was wrong, and the Matter side was finished off.

2026-08-15

v0.3 [beta]

Merged a Matter Door Lock endpoint into the same image that already carried the web UI, setup portal, and OTA — one firmware, not two. Landed the first real NFC frontend. Flashed and booted on an ESP32-WROOM-32, but a phone hadn’t opened anything yet.

2026-08-14

v0.2 [beta]

The first release that had actually run on hardware — v0.1 was written blind. Boots on its own, joins Wi-Fi through a setup portal, and updates itself over the air with a real rollback: a build that panics early or can’t serve its own UI gets put back automatically at the next reset.

2026-08-14

v0.1 [beta] — superseded

Compiled for both targets and was published without ever having run on real hardware. It boot-looped on first power-up and its web UI couldn’t load its own configuration. Both bugs were fixed in v0.2 the same day. Kept for history — don’t flash it.
