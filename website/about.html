Build the reader once.

Traditional mobile access systems are usually built around one ecosystem — an Apple-only door, or a Google-only one. Aliro is a Connectivity Standards Alliance protocol every major wallet speaks, so the reader doesn’t have to choose. Build it once; let the wallet ecosystem handle the credential experience.

What this is built on.

PieceWhat it gives us
espressif/esp-aliroThe Aliro protocol itself, prebuilt for ESP-IDF — crypto, state machine, session handling, fast transactions.
kormax/aliroIndependent protocol research — APDUs, AIDs, key derivation, wallet behavior.
rednblkx/HomeKey-ESP32Prior art on organizing an ESP32 access-control product — the pin tables and web layer’s general shape are adapted from it, credited in NOTICE.md.

What the SDK doesn’t give us, and this project therefore owns: the NFC chip driver, the credential store, the access decision, lock actuation, enrollment, and everything operational — UI, storage, OTA, MQTT, Matter.
